# Edit History

## 概要

CLIP STUDIO PAINTの「ヒストリー」パレットのように、AviUtl2の編集履歴を一覧で表示するプラグインです。

編集するたびに「何をどう変えたか」が分かる名前の項目が一覧に積まれ、項目をクリックするとその時点の状態まで戻せます。
戻す処理はAviUtl2本体の「元に戻す」「やり直し」を必要な回数だけ実行して行うため、戻した後も本体の「やり直し」で先へ進めます。

AviUtl2の表示言語が日本語・英語・韓国語・中国語のいずれの場合でも動作します。

https://github.com/user-attachments/assets/e82aabb8-fc6e-4756-937e-c6f41a7998be

## 導入方法

1. 次のどちらかの方法でインストールします。
   - AviUtl2カタログからインストールする。(推奨)(まだカタログに登録してないですが、近日中に登録予定です)
   - [リリース](../../releases)から `EditHistory.aux2` をダウンロードし、AviUtl2のプレビューウィンドウにドラッグ&ドロップする。
2. AviUtl2を起動します。
3. 左上メニューの「表示」→「EditHistory」で一覧のウィンドウを開きます。
   - 他のウィンドウと同じように、アプリケーションウィンドウの中に配置したり、分離したりできます。

### 削除方法

1. AviUtl2を終了します。
2. アプリケーションデータフォルダ内の次のファイル・フォルダを削除します。
   - `Plugin\EditHistory` フォルダ
   - `EditHistory.ini`(文字の大きさと右クリックのメニューの設定を保存するファイル。変えた場合のみ作られます)

(カタログからのアンインストールでも可能です)

## 機能

### 履歴の一覧

- 先頭は「開始時点」(プロジェクトを開いた時点、またはプラグインが監視を始めた時点)です。それより前には戻れません。
- 現在の状態の項目は強調表示され、下に線が引かれます。それより後ろの項目(やり直せる分)は灰色で表示されます。
- `Ctrl+Z` などのショートカットキーや、「編集」メニューの「元に戻す」「やり直し」で戻した・進めた場合も、一覧の現在位置が追従します。
- 本体のUndo履歴と同じく、シーンごとに別の履歴を持ち、最大100件まで記録します。プロジェクトを開いた時・新規作成した時は空になります。

### 項目の名前

変わった内容から、次のような名前を付けます。レイヤー番号は `[L1]` のように付けます。

| 操作 | 表示の例 |
| --- | --- |
| オブジェクトの追加・削除 | `図形[L2] を追加 ({対象の左端}秒)` <br> `図形[L2] を削除` |
| オブジェクトの移動 | `図形[L2] を移動 (開始 1.00秒→2.00秒)` <br> `図形[L2] を L3 へ移動`|
| オブジェクトの長さ変更 | `図形[L2] の長さを変更 (終了 1.00秒→2.00秒)` |
| オブジェクトの分割 | `図形[L2] を分割 (1.50秒)` |
| 複数のオブジェクトを同時に操作 | `3個のオブジェクトを移動 (開始 …)` <br> `2個のオブジェクトを分割 (1.50秒)` |
| トラックバーの値の変更 | `図形[L2] 標準描画 X 0.00→100.00` |
| 複数の項目を同時に変更 | `図形[L2] 標準描画 X 0.00→10.00, Y 0.00→20.00` |
| 移動方法 | `図形[L2] 標準描画 X,Y,Z に 直線移動 を適用` <br> `… の移動方法を解除` <br> `… の時間制御を編集` |
| 始点・終点の値変更 | `図形[L2] 標準描画 X 始点 0.00→10.00` |
| 中間点 | `図形[L2] 中間点を追加 (1.00秒)` <br> `図形[L2] 標準描画 X (中間点1) 0.00→50.00` |
| 参照式 | `… に参照式を設定 (X*2)` <br> `… の参照式を変更 (X*2→X*3)` <br> `… の参照式を解除` |
| テキストの入力 | `テキスト[L1] テキスト入力 (こんにちは)` |
| エフェクトの追加・削除・変更 | `図形[L2] ぼかし を追加` <br> `図形[L2] ぼかし を 発光 に変更` |
| エフェクトの並び替え | `図形[L2] ぼかし と 発光 を入れ替え` <br> `図形[L2] エフェクトの順番を変更` |
| ロック・表示 | `図形[L2] をロック` <br> `図形[L2] ぼかし を非表示` |
| オブジェクトの設定 | `図形[L2] のクリッピングを有効化` <br> `…の上のオブジェクトでクリッピングを解除` <br> `… をカメラ制御の対象から外す` <br> ` …をグループ制御の対象にする ` <br> `… の名前を変更 (なし→背景)` |
| レイヤーの設定 | `レイヤー1 非表示` <br> `レイヤー1 ロック` <br> `レイヤー1 名前「背景」` |
| レイヤー設定ウィンドウでの変更 (※) | `レイヤー1 X 標準→100` <br> `レイヤー1 音量 標準→50` <br> `レイヤー1 左右 標準→10` |
| オブジェクトのグループ化 (※) | `2個のオブジェクトをグループ化` <br> `2個のオブジェクトのグループを解除` |

- (※) の操作は、右クリックのメニューの「レイヤー設定・グループ化の変更も記録する (試験的)」が有効な場合(既定)だけ記録します。
- 同じエフェクトが1つのオブジェクトに複数ある場合は `ぼかし[2]` のように何番目かを付けます。
- 1回の操作で複数の内容が変わった場合は、代表の1件と「他N件」を表示します。
- 内容を特定できなかった編集は `(内容を特定できない編集)` と表示します。

### まとめて表示

次の場合は、本体のUndo履歴では1回ずつ別の項目ですが、一覧では1行にまとめて表示します(クリックすると、まとめた範囲の最後の状態へ移動します)。

- 同じテキスト・文字列の欄への、1文字ずつの連続した入力
- 同じオブジェクトの同じ項目への連続した変更(例: X座標を何度もドラッグした。X,YとXだけの変更が混ざっていてもまとめます)
- 同じパラメータの時間制御の連続した編集
- 同じレイヤーの同じレイヤー設定の連続した変更(試験的オプションを有効にした場合のみ検知)

### クリックで戻す・進める

一覧の項目をクリックすると、その時点の状態まで本体の「元に戻す」「やり直し」を繰り返します。

- 戻している間は、一覧の下端に「元に戻しています (残り N) Escで中止」の帯が表示され、マウスカーソルが待機の表示になります。
- `Esc` キーで途中で中止できます。
- 戻している間に行った編集操作は、戻し終わった後に順に実行されます。
- 一回の編集が重いプロジェクトでは、戻すのに時間がかかります。

### 文字の大きさ

一覧の上で `Ctrl` + マウスホイールを回すと、文字の大きさを50%〜300%の範囲で変えられます。変えた大きさは次回の起動時にも引き継がれます。

### 右クリックのメニュー

| 項目 | 説明 |
| --- | --- |
| 選択中・再生位置以外のオブジェクトの変更も記録する | 選択していないうえに再生位置にもないオブジェクトへの変更も記録します。(そのようなオブジェクトを変更する手段は普通ないと思われますが。)既定はオンです。<br>有効にすると、変化の見つからない編集のたびに全オブジェクトを読み直して探します。オブジェクトが多い(数百個以上の)プロジェクトでは編集が重くなります。 |
| レイヤー設定・グループ化の変更も記録する (試験的) | 有効にすると以下の変更も記録するようになります。試験的な機能で、既定はオンです。<br>・レイヤー設定ウィンドウでの座標XY・音量・左右の変更(`レイヤー1 X 標準→100` など)<br>・オブジェクトのグループ化・グループ解除(`2個のオブジェクトをグループ化` など)<br>どちらもプラグインから直接読めないため、プロジェクトを一時ファイルに保存して読みます。そのため若干編集が重くなります。<br>切り替えると、一覧は「開始時点」から取り直しになります。 |

## 既知の制限

- 右クリックのメニューで「レイヤー設定・グループ化の変更も記録する」を無効にした場合、レイヤー設定の変更とオブジェクトのグループ化・グループ解除は一覧に載らず、一覧とのずれが生じます。
- 右クリックのメニューで「選択中・再生位置以外のオブジェクトの変更も記録する」を無効にした場合、オブジェクトリストからの表示・非表示の切り替えなど、選択していないうえに再生位置にもないオブジェクトへの変更は一覧に載らず、一覧とのずれが生じます。
- 一覧と本体のUndo履歴が一致しなくなったことを検出した場合は、一覧を「開始時点」から取り直します(その時点より前には一覧から戻れなくなります。本体の「元に戻す」は引き続き使えます)。
  その際、AviUtl2のログに `[EditHistory] 履歴を取り直しました (理由)` と出力します。
- 本体の「元に戻す」「やり直し」「グループ化」「グループ解除」は、メニューの項目名で探しています。対応している表示言語は日本語・英語・韓国語・中国語で、それ以外の言語では動作しません。
