# Edit History

## 概要

CLIP STUDIO PAINTの「ヒストリー」パレットのように、AviUtl2の編集履歴を一覧で表示するプラグインです。

編集するたびに「何をどう変えたか」が分かる名前の項目が一覧に積まれ、項目をクリックするとその時点の状態まで戻せます。
戻す処理はAviUtl2本体の「元に戻す」「やり直し」を必要な回数だけ実行して行うため、戻した後も本体の「やり直し」で先へ進めます。

AviUtl2の表示言語が日本語・英語・韓国語・中国語のいずれの場合でも動作します。

v1.0から、AviUtl2本体がメモリ上に持っているUndo履歴を直接読み取って一覧を作るようになりました。
本体のUndo履歴そのものを見ているので、他のプラグインによる編集も含めて、本体の「元に戻す」と1件ずつ対応します。
項目の名前も、本体のUndo履歴が持つ変更前・変更後の値から作るため、編集のたびにオブジェクトやプロジェクトを読み直すことはありません。
本体の内部の構造に依存するため、動作を確認したAviUtl2の版は ver 2.1.19 です。
本体の更新で構造が変わり読み取れなくなった場合は、一覧に「この版のAviUtl2には対応していません」と表示し、記録を止めます(本体の動作には影響しません)。

## 導入方法

1. 次のどちらかの方法でインストールします。
   - AviUtl2カタログからインストールする。(推奨)(まだカタログに登録してないですが、近日中に登録予定です)
   - [リリース](../../releases)から `EditHistory.aux2` をダウンロードし、AviUtl2のプレビューウィンドウにドラッグ&ドロップする。
2. AviUtl2を起動します。
3. 左上メニューの「表示」→「EditHistory」で一覧のウィンドウを開きます。
   - 他のウィンドウと同じように、アプリケーションウィンドウの中に配置したり、分離したりできます。

### 削除方法

1. AviUtl2を終了します。
2. アプリケーションデータフォルダ内の次のファイル・フォルダを削除します。
   - `Plugin\EditHistory` フォルダ
   - `EditHistory.ini`(文字の大きさを保存するファイル。変えた場合のみ作られます)

(カタログからのアンインストールでも可能です)

## 機能

### 履歴の一覧

- 先頭は「開始時点」(プロジェクトを開いた時点、またはプラグインが監視を始めた時点)です。それより前には戻れません。
- 現在の状態の項目は強調表示され、下に線が引かれます。それより後ろの項目(やり直せる分)は灰色で表示されます。
- `Ctrl+Z` などのショートカットキーや、「編集」メニューの「元に戻す」「やり直し」で戻した・進めた場合も、一覧の現在位置が追従します。
- 他のプラグインによる編集や「元に戻す」も、本体のUndo履歴に積まれたものはそのまま一覧に載ります。
- 本体のUndo履歴と同じく、シーンごとに別の履歴を持ち、最大100件まで記録します。プロジェクトを開いた時・新規作成した時は空になります。

### 項目の名前

変わった内容から、次のような名前を付けます。レイヤー番号は `[L1]` のように先頭に付けます。

| 操作 | 表示の例 |
| --- | --- |
| オブジェクトの追加・削除 | `[L2]図形 を追加 ({対象の左端}秒)` <br> `[L2]図形 を削除` |
| オブジェクトの移動 | `[L2]図形 を移動 (開始 1.00秒→2.00秒)` <br> `[L2]図形 を L3 へ移動`|
| オブジェクトの長さ変更 | `[L2]図形 の長さを変更 (終了 1.00秒→2.00秒)` |
| オブジェクトの分割 | `[L2]図形 を分割 (1.50秒)` |
| 複数のオブジェクトを同時に操作 | `3個のオブジェクトを移動 (開始 …)` <br> `2個のオブジェクトを分割 (1.50秒)` |
| トラックバーの値の変更 | `[L2]図形 標準描画 X 0.00→100.00` |
| 複数の項目を同時に変更 | `[L2]図形 標準描画 X 0.00→10.00, Y 0.00→20.00` |
| 移動方法 | `[L2]図形 標準描画 X,Y,Z に 直線移動 を適用` <br> `… の移動方法を解除` <br> `… の時間制御を編集` |
| 始点・終点の値変更 | `[L2]図形 標準描画 X 始点 0.00→10.00` |
| 中間点 | `[L2]図形 中間点を追加 (1.00秒)` <br> `[L2]図形 標準描画 X (中間点1) 0.00→50.00` |
| 参照式 | `… に参照式を設定 (X*2)` <br> `… の参照式を変更 (X*2→X*3)` <br> `… の参照式を解除` |
| テキストの入力 | `[L1]テキスト テキスト入力 (こんにちは)` (増えた文字を緑、消えた文字を取り消し線付きの赤で表示) |
| 選択肢 | `[L2]図形 標準描画 合成モード 通常→乗算` |
| 色リスト | `段階グラデーション 中間色1 ff0000→00ff00` <br> `… 中間色2 を追加 (0000ff)` <br> `… 中間色1 を削除` <br> `… 中間色1 の位置 0→50` |
| エフェクトの追加・削除・変更 | `[L2]図形 ぼかし を追加` <br> `[L2]図形 ぼかし を 発光 に変更` |
| エフェクトの並び替え | `[L2]図形 ぼかし と 発光 を入れ替え` <br> `[L2]図形 エフェクトの順番を変更` |
| ロック・表示 | `[L2]図形 をロック` <br> `[L2]図形 ぼかし を非表示` |
| オブジェクトの設定 | `[L2]図形 のクリッピングを有効化` <br> `…の上のオブジェクトでクリッピングを解除` <br> `… をカメラ制御の対象から外す` <br> ` …をグループ制御の対象にする ` <br> `… の名前を変更 (なし→背景)` |
| レイヤーの設定 | `レイヤー1 非表示` <br> `レイヤー1 ロック` <br> `レイヤー1 名前「背景」` |
| レイヤー設定ウィンドウでの変更 | `レイヤー1 X 0→100` <br> `レイヤー1 音量 100→50` <br> `レイヤー1 左右 0→10` |
| オブジェクトのグループ化 | `2個のオブジェクトをグループ化` <br> `2個のオブジェクトのグループを解除` |

- 同じエフェクトが1つのオブジェクトに複数ある場合は `ぼかし[2]` のように何番目かを付けます。
- 1回の操作で複数の内容が変わった場合は、代表の1件と「他N件」を表示します。
- 図形の種類・ファイル・フォント等の項目は、変更後の値だけを `[L2]図形 図形 図形の種類 を 四角形 に変更` のように表示します(同じ項目を続けて変えた時は変更前の値も出します)。

### まとめて表示

次の場合は、本体のUndo履歴では1回ずつ別の項目ですが、一覧では1行にまとめて表示します(クリックすると、まとめた範囲の最後の状態へ移動します)。
まとめた行は、左端から番号までの部分が少し明るく表示されます。

- 同じテキスト・文字列の欄への、1文字ずつの連続した入力
- 同じオブジェクトの同じ項目への連続した変更(例: X座標を何度もドラッグした。X,YとXだけの変更が混ざっていてもまとめます。選択肢・フォント等の項目もまとめます。色リストは、同じ色の色・位置の変更が続く時だけまとめ、色の追加・削除はまとめません)
- 同じパラメータの時間制御の連続した編集
- 同じレイヤーの同じレイヤー設定の連続した変更

### クリックで戻す・進める

一覧の項目をクリックすると、その時点の状態まで本体の「元に戻す」「やり直し」を繰り返します。

- 戻している間は、一覧の下端に「元に戻しています (残り N) Escで中止」の帯が表示され、マウスカーソルが待機の表示になります。
- `Esc` キーで途中で中止できます。
- 戻している間に行った編集操作は、戻し終わった後に順に実行されます。
- 一回の編集が重いプロジェクトでは、戻すのに時間がかかります。

### 文字の大きさ

一覧の上で `Ctrl` + マウスホイールを回すと、文字の大きさを50%〜300%の範囲で変えられます。変えた大きさは次回の起動時にも引き継がれます。

## 既知の制限

- AviUtl2本体の内部の構造を読んでいるため、本体の更新で動作しなくなる可能性があります(その場合は一覧に表示して記録を止めます)。
- 他のプラグインが一度に複数の編集を行った場合など、一覧が確かめる前に次の編集が積まれた場合は、前の方の項目のうち
  テキストの入力は入力した文字だけ(`テキスト入力 (+b)`)、選択肢等の項目は値を省いて(`文字装飾 を変更`)表示します。
- 本体の「元に戻す」「やり直し」は、メニューの項目名で探しています(一覧のクリックで戻す時に使います)。対応している表示言語は日本語・英語・韓国語・中国語です。

## 更新履歴

- v1.0 (2026/11/24):
  - 編集履歴の取り方を変更。AviUtl2本体のメモリ上のUndo履歴を直接読み取るようにした
    (これまでは編集のたびに状態を読み比べ、キー入力・メニューの操作から元に戻す・やり直しを推測していた)
  - 他のプラグインによる編集・元に戻す、数値欄への入力、グループ化などで、一覧と本体の履歴がずれることが無くなった
  - 項目の名前も本体のUndo履歴の変更前・変更後の値から作るようにし、編集のたびのオブジェクトの読み直し・プロジェクトの一時保存を無くした
    (オブジェクトの多いプロジェクトでも軽くなった)
  - レイヤー設定の変更は値で表示するようにした(`レイヤー1 X 0→100`)
  - 選択肢の変更を「変更前→変更後」で表示するようにした(`合成モード 通常→乗算`)
  - 選択肢・フォント等の項目と、色リストの同じ色の連続した変更も、1行にまとめて表示するようにした
  - 色リストは、変わった色だけを名前付きで表示するようにした(`中間色1 ff0000→00ff00`、`中間色2 を追加 (0000ff)`)
  - テキストの入力は、増えた文字を緑、消えた文字を取り消し線付きの赤で表示するようにした
  - 複数の編集をまとめた行は、番号の欄を少し明るくして区別するようにした
  - レイヤー番号をオブジェクト名の前に出すようにした(`[L1]図形 を移動 …`)
  - 右クリックのメニューの設定(どちらも不要になった)を削除
- v0.2 (2026/10/6):
  - 新しいプラグイン・スクリプトを追加した後の起動(「スクリプト・プラグインの追加」の確認が出る起動)で、AviUtl2が異常終了する不具合を修正
- v0.1 (2026/9/28): 初版(プレリリース)
